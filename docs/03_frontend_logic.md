# docs/03_frontend_logic.md - 프론트엔드 타이머 & DOM 제어 지침

## 1. 개요
Vanilla JavaScript(`public/app.js`)를 사용하여 뽀모도로 타이머 카운트다운, 공부시간 누적, 목표 달성률 계산, 3단계 식물 성장 이미지 변경, 피드백 작성 및 목록 조회 DOM 조작을 담당합니다.

## 2. 세부 기능 구현 규칙
1. **목표 공부시간 설정 & 식물 성장 메커니즘**:
   * 목표 시간(분/시간 단위) 입력 및 저장.
   * `달성률 = (누적 공부시간 / 목표 공부시간) * 100` 계산.
   * 달성률 < 34% -> 씨앗 이미지(`seed.png`)
   * 34% <= 달성률 < 67% -> 새싹 이미지(`sprout.png`)
   * 달성률 >= 67% -> 꽃피우기 이미지(`flower.png`) 및 축하 애니메이션.
2. **뽀모도로 타이머 (공부시간 & 쉬는시간)**:
   * 사용자 지정 공부시간(예: 25분) & 쉬는시간(예: 5분) 설정.
   * `setInterval` 기반 카운트다운 타이머.
   * 공부시간 타이머가 00:00에 도달하면:
     - 알림음 재생 및 경고창 표시.
     - 설정된 공부시간이 '오늘의 내 공부시간' 변수에 자동 더해짐.
     - 식물 성장 달성률 및 이미지가 즉시 업데이트됨.
     - 쉬는시간 타이머 모드로 자동 전환 (선택적).
3. **비로그인 피드백 작성 및 Fetch 통신**:
   * 닉네임과 피드백 내용 입력 후 '전송' 버튼 클릭.
   * `POST /api/feedbacks` 호출.
   * 성공 시 입력창 초기화 및 `GET /api/feedbacks` 호출하여 화면 하단 목록 최상단에 피드백 렌더링.
4. **오류 메시지 처리**:
   * 목표 시간 0 설정, 타이머 음수 설정, 빈 피드백 전송 시 화면에 Red 톤의 안내 토스트 메세지 출력 ("올바른 시간을 입력해주세요.").

## 3. 완료 기준 & 검증 기준 (Acceptance Criteria)
* [ ] 타이머가 완료되면 공부시간이 정확히 누적되고 식물 단계(씨앗->새싹->꽃)가 자동으로 변경되는가?
* [ ] 피드백 전송 시 즉시 하단 목록에 반영되는가?
* [ ] 잘못된 입력 시 에러 토스트 메시지가 정상 표시되는가?
